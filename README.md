This is a test web application with a focus on the backend. It is an online store where users can browse and buy products. The product page is controlled by an admin, who can add or delete products and view available stock.



Web application is  built with **Flask**, **Flask-RESTX**, **Flask-JWT-Extended**, **Flask-Admin**, and **SQLAlchemy**
